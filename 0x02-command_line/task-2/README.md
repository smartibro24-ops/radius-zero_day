# Task 2 - File and Directory Management

## Commands practised
mkdir -p, touch, echo, cat, head, tail, wc -l, cp, mv, rm, ls -l, find

## Explanation of commands
- mkdir -p: creates directories, including parent directories if needed.
- touch: creates an empty file.
- cp: copies a file to another location.
- mv: moves a file, or renames it when the destination is a new name.
- rm: removes a file.
- cat, head, tail: display the contents of a file.
- wc -l: counts the lines in a file.

## Difference between > and >>
> overwrites the file with the new text. >> adds the text to the end of the file.

## File permissions
ls -l shows the permissions of each file, for example -rw-r--r--. The first
character is the file type. Then come the permissions for the owner (rw-),
the group (r--) and others (r--). After that come the owner, size, date and name.
